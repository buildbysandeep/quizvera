# **Quiz App**

A fast, scalable, and anti-cheat enabled quiz platform built for schools, colleges, coaching centers, and corporate training environments.

---

### 🌐 Live Demo

[https://saas-quiz.netlify.app/](https://saas-quiz.netlify.app/)

---

## 🚀 Tech Stack

**Frontend:** Next.js (React), TailwindCSS
**Backend:** Next.js API Routes
**Database:** MongoDB
**Authentication:** NextAuth
**Package Manager:** pnpm

---

## 🎯 Core Features

### 👨‍🏫 Admin

- Create, update quizzes
- Create bulk questions
- Track submissions
- Export results
- Analytics dashboard

### 📝 Quiz Engine

- Randomized question order
- Timer per quiz/session
- Leaderboard
- Multi-language
- Clean UI, mobile responsive

### 🔒 Anti-Cheating

- Focus detection
- Tab switch monitoring
- Idle/lock detection
- Analytics on violations

---

## 🌍 Target Users

Built for:

- Schools & Colleges
- Coaching centers
- Corporate training teams
- Remote learning environments

---

## 📦 Installation

```sh
pnpm install
pnpm prisma
pnpm dev
```

> Make sure MongoDB is running and environment variables are configured.

---

## 🔧 Environment Variables

Add your credentials inside `.env` – refer to `.env.example` for structure.
